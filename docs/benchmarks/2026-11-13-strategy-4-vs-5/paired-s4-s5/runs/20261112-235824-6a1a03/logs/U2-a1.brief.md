## Overall task
Let Cart.total accept several coupons: total(coupons=None) where coupons is None, a single coupon dict (as
today) or a list of coupon dicts. Reuse shop.pricing.apply_coupons(amount, coupons), which already accepts a
list. Rules: (1) an empty cart totals 0.0 whatever the coupons; (2) at most one percent coupon applies, the one
with the highest value, other percent coupons are ignored; (3) the percent coupon applies first and then every
fixed coupon is subtracted in the order given, regardless of the order of the list; (4) the result is never
below 0.0; (5) a coupon with an unknown type raises ValueError (same message as shop.pricing.apply_coupon);
(6) do not modify the list you are given. Example: subtotal 100 with [fixed 5, percent 10] is 85.0. Add unit tests.

## Architecture (decided; follow it)
Add a pure function apply_coupons(amount, coupons) to shop/pricing.py. It validates all coupon types, picks the highest percent coupon, applies it with apply_coupon, then applies each fixed coupon in order with apply_coupon, and clamps the result at 0.0. Cart.total normalizes its argument to a list, returns 0.0 for an empty cart, and otherwise delegates to apply_coupons.

Components:
- apply_coupons (modify shop/pricing.py): Apply several coupons to an amount following rules 2-5, without mutating the input.
- Cart.total (modify shop/cart.py): Normalize None/dict/list, handle the empty cart, and delegate to apply_coupons.
- pricing tests (modify tests/test_pricing.py): Tests for apply_coupons.
- cart tests (modify tests/test_cart.py): Tests for multi-coupon Cart.total.

### Invariants (must hold after every unit)
- apply_coupons never mutates its coupons argument.
- The return value is >= 0.0 and rounded via round2/apply_coupon.
- Unknown coupon types raise ValueError before any arithmetic.
Error handling: apply_coupons raises ValueError(f"unknown coupon type: {coupon['type']}") for the first coupon whose type is neither 'percent' nor 'fixed'. Cart.total lets it propagate, except when the cart is empty, where it returns 0.0 first.

## Decisions that bind this unit
- ADR-3 Normalization and the empty cart live in Cart.total: Cart.total(self, coupons=None): if not self.items: return 0.0; if coupons is None: coupons = []; elif isinstance(coupons, dict): coupons = [coupons]; return apply_coupons(self.subtotal(), coupons).
  Why: Rule 1 is literal: an empty cart returns 0.0 even if the coupons are invalid. Wrapping a dict creates a new list, so nothing is mutated.
  Rejected: Letting apply_coupons accept a single dict, which blurs its contract
  Constraint: Return the float literal 0.0 for an empty cart
