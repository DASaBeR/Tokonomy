## Overall task
Move the cart to exact integer-cents arithmetic without changing its public float API. The conversion helpers
already exist in shop/currency.py; move them into shop/money.py. shop/money.py must provide
to_cents(amount: float) -> int (dollars to cents, rounding half up, so to_cents(19.99) == 1999 and
to_cents(0.1 + 0.2) == 30) and from_cents(cents: int) -> float (cents / 100). In shop/cart.py items must store
the price as "unit_price_cents" (an int) instead of "unit_price"; Cart.add(sku, unit_price, qty=1) still takes
dollars. Add Cart.subtotal_cents() -> int computed with integer arithmetic only. A line costs
unit_price_cents * qty cents; on sale it is (unit_price_cents * qty * (100 - SALE_PERCENT) + 50) // 100, i.e. the
sale discount is applied to the whole line and rounded half up once. Cart.subtotal() returns
from_cents(subtotal_cents()), Cart.line_total(item) returns the line in dollars as before, and Cart.total(coupon)
keeps working. Add unit tests.

## Architecture (decided; follow it)
Add to_cents/from_cents to shop/money.py using Decimal-based half-up rounding. Cart converts dollars to cents once, in add(). A private integer helper _line_cents computes each line, and subtotal_cents sums those lines. line_total and subtotal convert back to float through from_cents. total still delegates to apply_coupon on the float subtotal.

Components:
- money helpers (modify shop/money.py): Add to_cents and from_cents alongside round2 and fmt.
- Cart (modify shop/cart.py): Store unit_price_cents, compute lines and the subtotal in integer cents, and expose the float API through from_cents.
- money tests (create tests/test_money.py): Unit tests for to_cents and from_cents.
- cart tests (modify tests/test_cart.py): Keep the existing tests and add cents-specific tests.

### Invariants (must hold after every unit)
- Every Cart.items entry has exactly the keys sku, unit_price_cents (an int) and qty.
- subtotal_cents() and _line_cents() return int and use only the int operations *, + and //.
- Cart.subtotal() == from_cents(Cart.subtotal_cents()).
Error handling: No new validation is added. A non-finite input to to_cents raises the Decimal error naturally.
Performance: Decimal is used only once per add(). All other arithmetic is plain int.
