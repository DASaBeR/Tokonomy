## Overall task
Add shop/cache.py with class TtlCache(ttl_seconds: float, max_size: int | None = None, clock=time.monotonic),
built on the LRU class in shop/lru.py. Methods: set(key, value), get(key, default=None), delete(key) -> bool,
"key in cache" and len(cache). An entry expires once clock() - stored_at >= ttl_seconds, so it is already gone
exactly at the ttl. set() on an existing key replaces the value and restarts its ttl; get() does not extend the
ttl. len() and "in" count only live entries. When max_size is set and a new key is inserted into a full cache,
expired entries are dropped first and only if it is still full is the least recently used live entry evicted;
both get() hits and set() count as use. Updating an existing key never evicts anything. A stored value of None
is a real value. delete() returns True only if a live entry was removed. The cache must be safe to use from many
threads, and instances must not share any state (no module-level mutable state). Add unit tests.

## Architecture (decided; follow it)
shop/lru.py provides LRU, an unbounded, non-thread-safe ordering store wrapping collections.OrderedDict (least recently used first). shop/cache.py provides TtlCache. It stores (value, stored_at) tuples in a per-instance LRU and guards every public method with a per-instance threading.Lock. It reads clock() once per public call, while holding the lock. Expiry, purging and eviction live in small private helpers that assume the lock is already held.

Components:
- LRU (create shop/lru.py): Ordered key/value store with recency operations: get (marks used), peek (no reorder), put (insert/replace, marks used), remove, pop_oldest, keys, len, contains.
- TtlCache (create shop/cache.py): Thread-safe TTL cache with optional max_size, built on LRU.
- LRU tests (create tests/test_lru.py): Unit tests for LRU.
- TtlCache tests (create tests/test_cache.py): Unit tests for TtlCache using a fake clock, including a multithreaded smoke test.

### Invariants (must hold after every unit)
- When max_size is set, len(self._store) <= max_size after every public call.
- Each LRU value inside TtlCache is a (value, stored_at) tuple.
- Every read or mutation of self._store happens while holding self._lock.
- clock() is called at most once per public method call.
Error handling: The constructor raises ValueError if ttl_seconds < 0, or if max_size is not None and max_size < 1. All other operations do not raise for missing or expired keys. LRU.pop_oldest raises KeyError when empty, but TtlCache only calls it when the store is non-empty.
Security: No module-level mutable state. The sentinel `_MISSING = object()` is an immutable identity marker and is allowed.
Performance: get, set, delete and contains are O(1), except when inserting into a full cache: that does an O(n) purge of expired entries. len() also purges in O(n).

## Decisions that bind this unit
- ADR-1 Create shop/lru.py because it is missing: Create shop/lru.py containing class LRU, an unbounded OrderedDict wrapper with no capacity and no locking.
  Why: The task requires building on shop/lru.py, which does not exist. Keeping LRU free of capacity rules lets TtlCache apply its own rule: drop expired entries first, then evict the least recently used.
  Rejected: Implementing TtlCache directly on OrderedDict (violates 'built on the LRU class').; Giving LRU its own max_size auto-eviction (it would evict live entries before expired ones).
  Constraint: LRU has no lock and no capacity.
  Constraint: LRU uses only collections.OrderedDict.

4. get(key, default=None): if key in self._data, call self._data.move_to_end(key) and return self._data[key]. Otherwise return default.

8. pop_oldest(): return self._data.popitem(last=False). This returns a (key, value) tuple and raises KeyError when empty.
9. keys() -> list: return list(self._data.keys()), ordered least to most recently used.
