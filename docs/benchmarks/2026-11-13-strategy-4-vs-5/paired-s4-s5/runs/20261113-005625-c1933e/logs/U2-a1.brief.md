## Architecture (decided; follow it)
shop/lru.py provides LRU, an unbounded, non-thread-safe ordering store wrapping collections.OrderedDict (least recently used first). shop/cache.py provides TtlCache. It stores (value, stored_at) tuples in a per-instance LRU and guards every public method with a per-instance threading.Lock. It reads clock() once per public call, while holding the lock. Expiry, purging and eviction live in small private helpers that assume the lock is already held.

Components:
- LRU (create shop/lru.py): Ordered key/value store with recency operations: get (marks used), peek (no reorder), put (insert/replace, marks used), remove, pop_oldest, keys, len, contains.
- TtlCache (create shop/cache.py): Thread-safe TTL cache with optional max_size, built on LRU.
- LRU tests (create tests/test_lru.py): Unit tests for LRU.
- TtlCache tests (create tests/test_cache.py): Unit tests for TtlCache using a fake clock, including a multithreaded smoke test.

### Invariants (must hold after every unit)
- When max_size is set, len(self._store) <= max_size after every public call.
- Each LRU value inside TtlCache is a (value, stored_at) tuple.
- Every read or mutation of self._store happens while holding self._lock.
- clock() is called at most once per public method call.
Error handling: The constructor raises ValueError if ttl_seconds < 0, or if max_size is not None and max_size < 1. All other operations do not raise for missing or expired keys. LRU.pop_oldest raises KeyError when empty, but TtlCache only calls it when the store is non-empty.
Security: No module-level mutable state. The sentinel `_MISSING = object()` is an immutable identity marker and is allowed.
Performance: get, set, delete and contains are O(1), except when inserting into a full cache: that does an O(n) purge of expired entries. len() also purges in O(n).

## Decisions that bind this unit
- ADR-2 One per-instance threading.Lock: TtlCache.__init__ creates self._lock = threading.Lock(). Each public method (set, get, delete, __contains__, __len__) wraps its whole body in `with self._lock:`. Private helpers never acquire the lock.
  Why: Simple, correct mutual exclusion. A non-reentrant lock is fine because helpers never re-acquire it.
  Rejected: RLock (not needed); Locking inside LRU (double locking, harder to reason about)
  Constraint: Public methods must not call other public methods of the same instance.
- ADR-3 Storage format and None handling: Store the tuple (value, stored_at) in the LRU. Detect absence with the module constant `_MISSING = object()` passed as the default to LRU.peek.
  Why: None is a real value, so it cannot also signal absence.
  Rejected: Using None as the absent marker; Catching KeyError
  Constraint: Never test `is None` to check presence.
- ADR-4 Expiry semantics: An entry is expired iff now - stored_at >= self._ttl. Expired entries found by get, delete or __contains__ are removed physically. len() purges all expired entries, then returns len(self._store). `in` does not count as use.
  Why: Matches the specification exactly. The spec names only get hits and set as use.
  Rejected: Using > (live at exactly the ttl); Marking an entry used on `in`
  Constraint: get() never changes stored_at.
- ADR-5 set() behaviour: If the key is physically present in the store (live or expired), overwrite it via put(key, (value, now)) and do no eviction. Otherwise, if max_size is set and the store is full, purge expired entries first, then call pop_oldest() while len >= max_size, then put.
  Why: Overwriting does not grow the store, so it never needs eviction. Re-setting an expired key behaves like a fresh insert with a new ttl.
  Rejected: Evicting before any set; Evicting the LRU entry without purging expired ones first
  Constraint: Purge expired entries before any LRU eviction.
- ADR-6 Constructor validation: Raise ValueError if ttl_seconds < 0. Raise ValueError if max_size is not None and max_size < 1.
  Why: Prevents nonsensical configurations at low cost.
  Rejected: No validation
  Constraint: ttl_seconds == 0 is allowed.

3. Private helper _expired(self, stored_at, now) -> bool: return now - stored_at >= self._ttl.
4. Private helper _purge_expired(self, now) -> None: for key in self._store.keys(): entry = self._store.peek(key); if self._expired(entry[1], now): self._store.remove(key).
5. Private helper _live_entry(self, key, now): entry = self._store.peek(key, _MISSING). If entry is _MISSING, return _MISSING. If self._expired(entry[1], now), call self._store.remove(key) and return _MISSING. Otherwise return entry. This does not reorder.
6. set(self, key, value) -> None: with self._lock: now = self._clock(). If key in self._store, call self._store.put(key, (value, now)) and return. Finally call self._store.put(key, (value, now)).
7. get(self, key, default=None): with self._lock: now = self._clock(); entry = self._live_entry(key, now). If entry is _MISSING, return default. Otherwise call self._store.get(key) to mark it used and return entry[0]. Never modify stored_at.
8. delete(self, key) -> bool: with self._lock: now = self._clock(); entry = self._live_entry(key, now). If entry is _MISSING, return False. Otherwise call self._store.remove(key) and return True.
9. __contains__(self, key) -> bool: with self._lock: return self._live_entry(key, self._clock()) is not _MISSING.
