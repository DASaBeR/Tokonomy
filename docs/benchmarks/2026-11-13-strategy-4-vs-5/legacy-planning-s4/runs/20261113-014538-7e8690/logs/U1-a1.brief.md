## Overall task
Add shop/cache.py with class TtlCache(ttl_seconds: float, max_size: int | None = None, clock=time.monotonic),
built on the LRU class in shop/lru.py. Methods: set(key, value), get(key, default=None), delete(key) -> bool,
"key in cache" and len(cache). An entry expires once clock() - stored_at >= ttl_seconds, so it is already gone
exactly at the ttl. set() on an existing key replaces the value and restarts its ttl; get() does not extend the
ttl. len() and "in" count only live entries. When max_size is set and a new key is inserted into a full cache,
expired entries are dropped first and only if it is still full is the least recently used live entry evicted;
both get() hits and set() count as use. Updating an existing key never evicts anything. A stored value of None
is a real value. delete() returns True only if a live entry was removed. The cache must be safe to use from many
threads, and instances must not share any state (no module-level mutable state). Add unit tests.

## Your unit: U1 - Add LRU class in shop/lru.py with unit tests
shop/lru.py is not in the repository, so create it. Add `class LRU` backed by `collections.OrderedDict`. It is a plain recency-ordered map: it has no capacity, does no automatic eviction and has no locking. Create the OrderedDict in `__init__` as `self._data`.

API:
- `put(key, value) -> None`: insert or replace the value and mark the key most recently used (`move_to_end`).
- `get(key, default=None)`: if the key is present, mark it most recently used and return its value. Otherwise return `default`.
- `peek(key, default=None)`: like `get`, but does not change the order.
- `remove(key) -> bool`: delete the key. Return True if it was present, otherwise False.
- `pop_lru() -> tuple`: remove and return `(key, value)` for the least recently used entry. Raise `KeyError` if empty.
- `keys() -> list`: a snapshot list of keys, least recent first.
- `__len__` and `__contains__`. `__contains__` does not change the order.

A stored value of None is a normal value. Add a short module docstring and method docstrings.

Tests go in tests/test_lru.py using unittest, in the same style as the existing tests. Cover:
- put/get round-trip
- get of a missing key returns the default
- get moves the key to most recent, checked via `keys()` and `pop_lru`
- peek does not reorder
- put on an existing key replaces the value and moves it to most recent
- remove returns True/False correctly
- pop_lru on an empty LRU raises KeyError
- None is stored and returned
- two instances do not share state

Files expected to change: shop/lru.py, tests/test_lru.py
