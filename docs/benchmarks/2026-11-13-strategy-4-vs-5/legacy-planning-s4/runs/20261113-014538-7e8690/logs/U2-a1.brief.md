## Your unit: U2 - Add TtlCache in shop/cache.py built on LRU, with unit tests
Create shop/cache.py with `class TtlCache` and constructor `__init__(self, ttl_seconds: float, max_size: int | None = None, clock=time.monotonic)`. Raise ValueError if `max_size` is not None and `max_size < 1`.

Per-instance state:
- `self._ttl`
- `self._max_size`
- `self._clock`
- `self._lru = LRU()` (from shop.lru)
- `self._lock = threading.RLock()`

Use a private module-level immutable sentinel, `_MISSING = object()`, so that a stored None can be told apart from a missing key.

The LRU stores `(value, stored_at)` tuples. Define `_expired(stored_at, now)` as `now - stored_at >= self._ttl`, so an entry is already gone exactly at the ttl.

Every public method takes the lock for its whole body and calls `self._clock()` once.

- `set(key, value)`:
  - If the key exists in the LRU (live or expired), `put` it with `(value, now)`. This replaces the value, restarts the ttl and marks it as used. An update never evicts.
  - Otherwise, if `max_size` is set and `len(self._lru) >= max_size`, first drop all expired entries using a private `_purge(now)`. `_purge` iterates `self._lru.keys()`, uses `peek` and calls `remove` on expired entries. If the LRU is still at least `max_size` long, call `pop_lru()` once. Then `put` the new entry.
- `get(key, default=None)`:
  - Look the key up with `peek`. If it is missing, return `default`.
  - If it is expired, `remove` it and return `default`.
  - Otherwise call `self._lru.get(key)` to mark it as used and return the value.
  - Do NOT change `stored_at`.
- `delete(key) -> bool`: use `peek`. If the key is missing, return False. If it is expired, remove it and return False. If it is live, remove it and return True.
- `__contains__(key)`: return True only for a live entry. Do not change recency. Removing the entry if it has expired is fine.
- `__len__()`: call `_purge(now)`, then return `len(self._lru)`.

Tests go in tests/test_cache.py using unittest. Use a fake clock object with a mutable `t` attribute and `__call__` returning `t`, and advance time manually. Cover:
